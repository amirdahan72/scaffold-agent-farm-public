# Resources

Drop reference files here before running the agent farm. These are shared across all runs.

## Suggested Resources

- **Example status email** — a `.txt` or `.md` file with a previous VP-level status email you liked. The Email Writer sub-agent will match its tone and format.
- **Account context** — any markdown notes about the OpenAI account (key contacts, history, strategic priorities).

## How to Add Resources

1. Drop files into this folder (`work/resources/`)
2. When the agent starts, it will pause at Phase 0 and ask if you have resources to add
3. Confirm and proceed — collectors will read these files before querying Work IQ
